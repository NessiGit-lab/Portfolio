Endlings

Overview

  • 2D Metroidvania Plattformer with turn based Combat

  • Originally made as a Bachelor thesis

  • Creature Collector with branching story paths

  • Solo developed project

My Contributions

  • Combat Design

    1. Type system for a strength and weakness chart
    2. Attribute system for further combat balancing
    3. Move consumption, status effects and other smaller balancing
    4. Unique Boss battles, set in the combat screen and the overworld

  • UI Design

    1. Input definition and layout
    2. Design of the Creatures (Endlings) within the game
    3. Main HUD, Main-menu and Battle interface
    4. Visual of the game world biomes
    5. Three Main-character designs (male,female, non-binary)

  • World Design

    1. Design of six biomes with unique environment and events
    2. Path progression and Story-Event planning
    3. Branching story path and trigger-events

  • QA Testing

    1. Prototyping within Godot
    2. Manual testing and readjusting of movement mechanics
